## Auxiliary Research — GitHub, GitHub Desktop, and VS Code

### What is GitHub?
GitHub is a cloud platform for hosting Git repositories. Git tracks the history of your code locally; GitHub adds a shared online home for it, plus collaboration tools — issues, pull requests, code review, project boards, CI/CD (Actions), and security scanning. It's owned by Microsoft and is the largest code host in the world.

### Why should I use GitHub?
- **Backup and history:** your code lives off your machine, and every change is versioned and reversible.
- **Collaboration:** teammates and supervisors can view, review, and contribute through pull requests.
- **Organization:** issues and projects keep tasks, bugs, and discussions next to the code.
- **Automation:** Actions can test, build, and deploy on every push.
- **Portfolio:** public repos show your work to employers and the community.

### What is GitHub Desktop?
A free graphical app (Windows/macOS) for working with Git and GitHub without the command line. You can clone repos, see changed files, write commits, push/pull, and switch or create branches with buttons instead of commands. It's a beginner-friendly way to learn the Git workflow visually.

### Why GitHub over other code repository platforms?
Alternatives include GitLab, Bitbucket, and Azure DevOps — all capable. GitHub stands out for:
- **Largest community and ecosystem** — most open-source projects live there, so collaboration and discoverability are easiest.
- **Integrated tooling** — Actions, Copilot, Codespaces, Dependabot, and Pages are built in.
- **Industry standard** — most employers and tools expect GitHub familiarity.
- **Generous free tier** — unlimited public and private repos.

(GitLab is often preferred for self-hosting; Bitbucket for teams already on Jira/Atlassian.)

### Why do GitHub and VS Code work so well together?
Both are made by Microsoft, so the integration is first-class:
- **Built-in Git** in VS Code's Source Control panel — stage, commit, push, and pull without leaving the editor.
- **GitHub Pull Requests extension** — review and comment on PRs and issues inside VS Code.
- **GitHub Copilot** — AI code completion and chat, signed in with your GitHub account.
- **Codespaces / github.dev** — open any repo in a browser-based VS Code (press `.` on a repo page).
- **Settings Sync** via your GitHub account keeps your editor setup consistent across machines.
